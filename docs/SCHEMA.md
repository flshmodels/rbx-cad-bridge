# Relay record schema

Records are nested under a session and game-server namespace. Collection entries are JSON objects keyed by stable event ID or Roblox user ID. All timestamps in responses are Unix milliseconds generated by the relay. The game sends {"$timestamp":true} markers; these are resolved on receipt. This is a relay convention and has no Firebase dependency.

## Calls

| Field | Type | Meaning |
| --- | --- | --- |
| source | string | Always roblox |
| nature | string | Filtered incident summary, 3–80 characters |
| description | string | Filtered details, up to 300 characters |
| priority | string | low, medium, high, or emergency |
| location | string | Server-derived zone/coordinates |
| status | string | pending; no CAD dispatch actions in this release |
| callerUserId | integer | Caller Roblox user ID |
| callerName | string | Caller Roblox username |
| createdAt | number | Relay acceptance time; preserved on duplicate PUT |

## Units

| Field | Type | Meaning |
| --- | --- | --- |
| source | string | Always roblox |
| userId | integer | Roblox user ID; must match the record key |
| username | string | Roblox username |
| callsign | string, optional | CadCallsign player attribute, maximum 50 characters |
| status | string | offline, available, busy, en_route, on_scene, or panic |
| lastSeen | number | Latest game heartbeat or update accepted by the relay |

The bundled game integration sets available on duty, offline on exit, and panic on /panic. Other valid status values are reserved for game-side extensions. No department, shift hours, avatar, vehicle, or plate registration is inferred from a unit record. Add explicit fields and validation if your project needs them.

## Panics

| Field | Type | Meaning |
| --- | --- | --- |
| source | string | Always roblox |
| userId, username | integer, string | Triggering on-duty player |
| callsign | string, optional | Server-side CadCallsign attribute |
| location | string | Server-derived location |
| status | string | active |
| createdAt | number | Relay receipt time |

Panic alerts expire after five minutes. Calls and abandoned units expire after 24 hours. Offline status is derived after 150 seconds without a unit heartbeat.
